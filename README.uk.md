# ScreenAI

Невеликий оверлей для Windows поверх усіх вікон. Натискаєте **O** — він робить
знімок монітора, на якому курсор, надсилає його моделі ШІ, що бачить
зображення, і показує відповідь у правому верхньому куті екрана.

Зроблений для тестів, задач і питань на екрані: стандартна інструкція просить
модель знайти завдання й відповісти коротко. C# на .NET 9 і WinForms, без
залежностей, окрім самого фреймворку. Інтерфейс українською.

## Що тут варто пояснити

### Дві моделі навипередки, відповідь сама покращується

Кожен знімок іде одразу двом моделям: **швидкій** і **точній**. Швидка
отримує ту саму інструкцію плюс «Be very short.» Її відповідь з'являється
першою, жовтим. Коли допрацює точна модель, її відповідь заміняє швидку,
білим. Рядок стану в реальному часі показує, скільки секунд працює кожна.

Якщо точна модель помилилася, лишається швидка відповідь; якщо обидві —
показується помилка. Повторне натискання **O** скасовує поточний запит і
починає новий.

### Оверлей, якого немає на власному знімку

Вікно виключене із захоплення екрана через `SetWindowDisplayAffinity`
(`WDA_EXCLUDEFROMCAPTURE`), тож попередня відповідь не потрапляє ні в
наступний знімок, ні в будь-який інший запис екрана. Крім того, крізь нього
проходять клацання, воно ніколи не забирає фокус і не має кнопки на панелі
завдань: вікно, в якому ви працюєте, лишається активним.

### Вставте будь-який ключ — програма сама визначить, чий він

У налаштуваннях ви вставляєте ключ API, і ScreenAI визначає провайдера.
Відомі префікси вирішують одразу (`sk-or-` OpenRouter, `sk-ant-` Anthropic,
`AIza` Gemini, `xai-` xAI, `gsk_` Groq, `fw_` Fireworks, `tgp_` Together,
`sk-proj-` OpenAI). Неоднозначний ключ по черзі пробується на ендпоінті
`/models` імовірних провайдерів, доки один його не прийме.

Списки моделей беруться в самих провайдерів і фільтруються до тих, що
розуміють зображення, тож нові моделі з'являються без оновлення програми.

## Провайдери

OpenRouter, OpenAI, Anthropic, Gemini, xAI (Grok), Groq, Mistral, Together,
Fireworks, локальна Ollama (`localhost:11434`, без ключа) і будь-який свій
OpenAI-сумісний сервер за базовою адресою. Ключ DeepSeek розпізнається, але
не приймається, бо API DeepSeek не приймає картинок; програма пропонує
використати DeepSeek через OpenRouter.

Типово — `google/gemini-2.5-flash` (швидка) і `google/gemini-2.5-pro` (точна)
через OpenRouter. Для кожної ролі можна обрати будь-якого провайдера й модель.

## Клавіші

| Клавіша | Дія |
|---|---|
| `O` | знімок і запит; повторне натискання скасовує попередній запит |
| `H` | сховати чи показати оверлей (запит при цьому не зупиняється) |
| `Alt+K` | налаштування |
| `Alt+Q` | закрити програму |

Клавіші працюють глобально через низькорівневий хук клавіатури. `O` і `H`
однаково передаються активній програмі, тож якщо друкувати слово з літерою
«o» в іншому вікні, це теж запускає знімок. Поки фокус у вікні налаштувань,
вони ігноруються.

Знімок зменшується до ширини не більше 1920 px і надсилається як JPEG.

Інструкцію для моделей (формат відповідей на тести, задачі, формули, код)
можна змінити в налаштуваннях і повернути стандартну.

## Приватність

- Налаштування разом із ключами API зберігаються **відкритим текстом** у
  `%APPDATA%\ScreenAI\settings.json`. Необроблені помилки дописуються в
  `%APPDATA%\ScreenAI\error.log`.
- Знімок надсилається лише провайдерам двох обраних моделей і лише тоді,
  коли ви натискаєте **O**.
- Коли ви додаєте ключ, він надсилається визначеному провайдеру, щоб
  перевірити його й завантажити моделі. Ключ без упізнаваного префікса може
  бути спробуваний у трьох провайдерів (для ключів `sk-` — OpenAI і DeepSeek,
  для решти — Mistral, Together і OpenAI), доки один його не прийме.
- Немає телеметрії, перевірки оновлень і автозапуску.

## Запуск і збірка

Для збірки потрібен .NET 9 SDK; опублікована збірка залежить від
фреймворку, тож для запуску має бути встановлений .NET 9 Desktop Runtime.

```powershell
dotnet run                               # запуск із вихідного коду
dotnet publish -c Release                # один файл ScreenAI.exe (win-x64)
```

Готовий файл з'являється в `bin\Release\net9.0-windows\win-x64\publish\`.
Одночасно працює лише одна копія. Поки не додано жодного ключа, або якщо
запустити з `--settings`, на старті відкриваються налаштування.

Збірки: див. Releases.

```
Program.cs        оверлей, знімок екрана, глобальний хук клавіатури
Providers.cs      список провайдерів, визначення ключа, списки моделей, запити
Settings.cs       файл налаштувань і стандартна інструкція
SettingsForm.cs   вікно налаштувань
```
